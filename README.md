# 🎮 Number Guessing Game

A simple and interactive **Number Guessing Game built using Java**. The computer generates a random number between 1 and 100, and the player must guess the correct number within 7 attempts.

## ✨ Features
- 🎲 Random number generation
- 🔢 Number range from 1 to 100
- ❤️ Maximum 7 attempts per round
- ⬆️ Hints for guesses that are too low
- ⬇️ Hints for guesses that are too high
- ✅ Input validation for invalid entries
- 🏆 Score tracking across multiple rounds
- 🔄 Option to play again

## 🎯 How to Play
1. Start the game.
2. Guess a number between 1 and 100.
3. Enter your guess when prompted.
4. Follow the hints:
   - **Too low:** Try a higher number.
   - **Too high:** Try a lower number.
5. Guess correctly within 7 valid attempts to win.
6. Earn points based on the number of attempts used.
7. Enter `yes` to play another round or `no` to exit.
